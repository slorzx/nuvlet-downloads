# Nuvlet pilot downloads

This public repository is reserved for verified Nuvlet pilot installers and their SHA256 checksums. Application source is maintained separately in a private repository.

The website at https://nuvlet.com is being prepared for a small adult-managed pilot. A release being staged here does not mean hosting, Google sign-in, email delivery or live AI have been commissioned.

Apple Silicon Mac and Windows x64 are the current native build targets. Intel Mac is unavailable. Mac Developer ID signing/notarization and Windows Authenticode signing are pending. Real camera, microphone, speaker and prototype acceptance still require the target devices.

See each release's notes for its actual status and supported operating systems. Never post credentials, account exports, child data or private backups here.
